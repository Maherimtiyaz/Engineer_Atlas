- Islām: outward submission (the five pillars)

- Māturīdī / most Ḥanafīs: assent of the heart (with the tongue); deeds are its fruit

- Atharī / ḥadīth scholars: belief, speech and action; increases and decreases

# 1.1 How computers work — Day 3: from code to execution
Date: 2026-11-26

## The CPU loop
Fetch -> decode -> execute -> next. Everything, Python included, ends up as this.

## How Python runs
source (.py) -> bytecode (.pyc) -> CPython's interpreter loop (in C) runs one
bytecode at a time. Each bytecode = many machine instructions, so pure Python
loops are slow; NumPy loops run in C over contiguous memory.

## Memory hierarchy (rough)
L1 ~1 ns | L2 ~4 ns | L3 ~10-40 ns | RAM ~100 ns | SSD ~100 µs | network ~100 ms
Sequential access is fast (64-byte cache lines + prefetching); random access misses.

## The OS layer (cpu.land)
Interrupts and timers let the OS switch programs; the kernel runs privileged,
your program in user mode.
