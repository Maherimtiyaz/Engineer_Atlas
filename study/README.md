# Study plans

Every morning a scheduled Claude task writes `plans/YYYY-MM-DD.md` with the day's
Islamic Studies and AI/Backend plan (time blocks, resources, notes to save) and
advances `state.json`.

To change where you are, edit `state.json` (topic ids are the ones in the site URLs,
e.g. `#t-howcomp`), or reply to that morning's session with what you finished.
